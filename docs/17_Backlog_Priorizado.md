# 17. Backlog Inicial Priorizado

Se propone una ejecución en 4 Sprints de 2 semanas cada uno (MVP):

## Sprint 1: Cimientos y Seguridad
*   Configuración del entorno (Java 21 + Spring Boot + PostgreSQL).
*   Implementación del Módulo de Seguridad (Login/Registro).
*   Maquetación base en Angular (Tailwind + Material).

## Sprint 2: Core de Eventos e Inscripción
*   CRUD de Eventos y Categorías.
*   Catálogo público de eventos con filtros.
*   Flujo de inscripción para eventos gratuitos.

## Sprint 3: Pagos y Control de Acceso
*   Carga y validación de comprobantes de pago.
*   Generación de QRs y credenciales digitales.
*   Módulo de escaneo de asistencia para organizadores.

## Sprint 4: Certificación y Cierre
*   Generación automática de certificados en PDF.
*   Portal de verificación de certificados.
*   Dashboard administrativo y reportes básicos.
*   Pruebas integrales y despliegue inicial.
