# Diagramas de diseño

Los archivos `.wsd` de esta carpeta son material de diseño histórico y no deben considerarse contratos vigentes sin reconciliación. Algunos nombres reflejan conceptos legacy (por ejemplo, control de acceso); validar cada diagrama contra los tres roles actuales (`ADMINISTRADOR`, `ORGANIZADOR`, `USUARIO`), estados reales y API `/api/v1` antes de incluirlo en la monografía o en una defensa.

La fase E3.4 no editó los diagramas. Su actualización requiere una revisión posterior de modelo, casos de uso, secuencias y permisos; consultar [reconciliación E3.3](../auditoria/E3_3_RECONCILIACION_DOCUMENTO_SISTEMA.md) y [alineación E3.4](../auditoria/E3_4_ALINEACION_DOCUMENTAL.md).
