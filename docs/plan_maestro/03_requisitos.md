# 03. Requisitos funcionales reconciliados

Conservar 13 RF y sus IDs/prioridades de monografía. Criterios detallados: `docs/07_Requerimientos_Funcionales.md`. Estados de implementación: `docs/12_Matriz_de_Trazabilidad.md`. Este plan auxiliar no puede cambiar la prioridad normativa.

| ID | Requisito | Prioridad |
|---|---|---|
| RF-01 | Registro, autenticación y recuperación segura de acceso | MUST |
| RF-02 | Solicitar condición de organizador | SHOULD |
| RF-03 | Crear, gestionar y enviar eventos a revisión | MUST |
| RF-04 | Revisar y gestionar eventos enviados a revisión | MUST |
| RF-05 | Consultar, buscar y ver detalle de eventos publicados | MUST |
| RF-06 | Gestionar inscripción a eventos gratuitos y pagados | MUST |
| RF-07 | Registrar pagos, presentar comprobantes y validar pagos | MUST |
| RF-08 | Registrar asistencia por sesión mediante QR y geolocalización | MUST |
| RF-09 | Generar, consultar y descargar certificados elegibles | SHOULD |
| RF-10 | Consultar historial propio de inscripciones, pagos, asistencias y certificados | SHOULD |
| RF-11 | Gestionar categorías de eventos | SHOULD |
| RF-12 | Consultar dashboards y exportar reportes disponibles | COULD |
| RF-13 | Verificar públicamente un certificado por código | COULD |

Conteo: 13 RF; 7 MUST; 4 SHOULD; 2 COULD; porcentaje MUST = 7/13 × 100 = 53,85 %. QR pago se integra como criterios de RF-03, RF-05 y RF-07; no crear RF-14.
