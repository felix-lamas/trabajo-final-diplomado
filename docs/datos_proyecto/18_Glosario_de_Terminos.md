# 18. Glosario de Términos

*   **UAJMS:** Universidad Autónoma Juan Misael Saracho.
*   **JWT (JSON Web Token):** Estándar para la creación de tokens de acceso que permiten la propagación de identidad entre cliente y servidor.
*   **Monolito Modular:** Estilo arquitectónico que organiza el código en módulos lógicos independientes dentro de un mismo proceso de despliegue.
*   **UUID:** Identificador Único Universal, utilizado para el código de verificación de los certificados.
*   **Participante Interno:** Usuario que forma parte de la planilla docente, administrativa o estudiantil de la UAJMS.
*   **Validador Financiero:** Rol administrativo encargado de verificar que los depósitos bancarios coincidan con los comprobantes subidos por los usuarios.
*   **Credencial Digital:** Documento en formato digital que contiene el QR de acceso y datos del participante para un evento específico.
*   **Carga Horaria:** Cantidad de horas académicas que se certifican al finalizar un evento.
*   **Lazy Loading:** Técnica de optimización en Angular que carga los módulos del frontend solo cuando el usuario accede a ellos.
