# 11. Historias de Usuario

Siguiendo el formato: *Como [Actor], quiero [Acción] para [Beneficio].*

## 11.1. Gestión de Eventos
*   **HU-01:** Como estudiante, quiero ver una lista de eventos próximos para saber en cuáles puedo participar.
*   **HU-02:** Como coordinador, quiero definir el número de cupos de un taller para no exceder la capacidad del aula física.
*   **HU-03:** Como administrador, quiero categorizar los eventos (taller, charla, congreso) para que los usuarios los encuentren fácilmente.

## 11.2. Inscripciones y Pagos
*   **HU-04:** Como participante externo, quiero inscribirme a un curso de pago subiendo mi comprobante para asegurar mi cupo.
*   **HU-05:** Como validador financiero, quiero ver una lista de pagos pendientes para aprobarlos rápidamente.
*   **HU-06:** Como usuario, quiero recibir un correo de confirmación cuando mi pago sea aprobado para estar tranquilo.

## 11.3. Asistencia y Control
*   **HU-07:** Como participante, quiero tener mi credencial QR en mi celular para no tener que imprimir nada.
*   **HU-08:** Como registrador de asistencia, quiero escanear el QR desde la web para que el registro sea automático y evitar filas.

## 11.4. Certificación
*   **HU-09:** Como asistente, quiero descargar mi certificado en PDF después de cumplir con la asistencia para añadirlo a mi CV.
*   **HU-10:** Como empleador, quiero escanear el código de un certificado para verificar que sea auténtico y emitido por la UAJMS.
