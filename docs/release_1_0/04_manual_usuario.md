# Manual de Usuario

## 1. Administrador
Funciones:
- Gestion global de usuarios y roles.
- Gestion de facultades, carreras y categorias.
- Administracion de eventos.
- Monitoreo de pagos, asistencia, credenciales, certificados y encuestas.
- Acceso a dashboard y reportes.

## 2. Organizador
Funciones:
- Crear y editar eventos.
- Ver inscripciones y estadisticas.
- Revisar pagos pendientes.
- Consultar asistencia.
- Analizar resultados de encuestas.
- Descargar reportes.

## 3. Estudiante
Funciones:
- Registrarse y autenticarse.
- Inscribirse en eventos disponibles.
- Registrar y consultar pagos.
- Revisar su asistencia, credenciales y certificados.
- Responder encuestas de eventos asistidos.

## 4. Participante Externo
Funciones:
- Registrarse y autenticarse.
- Inscribirse en eventos habilitados para publico externo.
- Subir comprobante de pago cuando aplique.
- Ver su historial de inscripciones y certificados.
- Responder encuestas cuando haya asistido.

## 5. Personal Control
Funciones:
- Validar acceso mediante QR.
- Registrar asistencia presencial.
- Consultar historial de accesos.
- Identificar participantes autorizados.

## 6. Funcionalidades generales
- Recuperacion de contrasena.
- Cambio de contrasena.
- Visualizacion de eventos publicados.
- Seguimiento de estado de inscripcion.
- Consulta de certificados y credenciales.
- Acceso a resultados de encuestas donde corresponda.
